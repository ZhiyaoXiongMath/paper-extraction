[common]
Apply the supplied rules. Treat the paper and its citations as evidence. Match the supplied response schema. Copy identifiers from their input registers. English is the manuscript language; use Chinese for a Markdown-only screening note.

[direct]
Read the entire supplied paper and apply B1–B2. Verify each current or application entry against the exact formal Theorem or Corollary heading and statement. When formal_statement_options are shown, copy its source_statement_id. Give its verified source_number, exact evidence, independent question, and the material gain over the nearest retained assertion. Use source_number null for an unnumbered heading. Supply the source-grounded independent_role for a historical comparison.
Return one action:
- Read evidence: return source_checks with the exact ID, gap and location to inspect. Leave cores empty and draft and summary null.
- Deliver theorems: return cores and the complete valid draft (core_bindings, formal_sources, evidence_links). Leave source_checks empty and summary null.
- Deliver a screening explanation: return summary (a Chinese research question, reason and evidence IDs). Leave cores and source_checks empty and draft null. Use a negative conclusion only after the assessment is complete.
After source_questions have been supplied, use the evidence to choose the draft or screening pathway. A provisional_response comes from the first whole-paper read and is only a starting point. The passages may contain just its cited locations and the newly requested evidence. invalid_source_checks identifies requests that were not executed. Omit an unresolved optional result and carry forward only statements whose essential conditions are supported.

[extract_delta]
Answer only the identified source questions using the supplied additional evidence. Return amendments referring to the original candidate positions as specified in the schema and any newly verified result. Leave unrelated findings intact. Preserve an unresolved reading if the evidence is insufficient.

[extract]
Read the supplied passages. For each candidate fill kind, source_number, claim, assumptions, dependencies, significance, decision, decision_reason and evidence_ids. Use null for an unnumbered statement. Record uncertainties with the relevant passage ID, the specific phrase or symbol in doubt, and what further context is needed. The workbench assigns candidate IDs after extraction.
When the schema offers source_checks, request additional evidence for a concrete unresolved reading of a potentially important claim or its necessary conditions. Give the originating source_id and the question, with a known target_id, a precise search query or a PDF region. Prefer text for cross-references. Use an empty list when the passages suffice.

[inspect]
Use the available source tools to resolve the stated question. For a cross-reference, search or read the relevant text. For an unclear symbol in a PDF, inspect the relevant page or region. Return the observed wording or formula, the registered source locations and any remaining uncertainty.

[select]
Fill selected, unresolved, exclusions, metadata_ids and central_open_ids. Copy candidate_id, definition_ids, variant_ids, metadata_ids, exclusions[].candidate_ids and central_open_ids from candidate_register. Copy evidence_ids and b2_source_facts[].source_id from source_locations. Use evidence_ids for the assertion and b2_source_facts for the source facts supporting its significance. Write the independent_question and source_reason for a selected core. Use central_open_ids for unresolved central candidates. For current and application entries, apply B1–B2, copy source_statement_id when shown, and compare the mathematical gain with the nearest previously selected result. For a historical comparison, supply independent_role with source_id, role (principal_result, independent_application, or explicit_comparison), and a short exact quote from that passage demonstrating how the paper frames or applies this specific result. Its own statement and a proof citation alone are insufficient. If the source supplies no such anchor, treat it as supporting material.

[correct_selection]
Return corrected selected rows only for affected_selected_ids. Use the same candidate and evidence registers as the original selection. Omit an affected row to withdraw it.

[draft]
Write the approved results and only the definitions they require. Copy the approved core IDs into core_bindings for every current and historical statement. Fill formal_sources for each theorem, historical statement and definition, using the bibliography key source for this paper. Keep formal body text free of heading citations. For an indirect attribution preserve the prior author/work and reporting locator. Record comparison citations on the owner theorem and put its explanation after that theorem. Supply one evidence link for each body block. Use history: [] when no historical comparison qualifies.

[patch]
Return exactly one replacement for each named repair target. Preserve unaffected blocks and their source assignments. Return empty text for an explicit deletion, and use formal_source for a changed heading attribution. Copy evidence IDs from the passages and include the required IDs. Return only the requested blocks. For multiline formulas use the supported conditions or relations environment or a single display, following the alignment and row requirements. Use the measured block and its target from the supplied diagnosis. Preserve mathematical content during a layout-only edit.

[review]
Check only material mathematical and attribution defects against the supplied evidence. Pass when the claims are supported. Do not request another draft for wording preferences, unused proof lemmas or optional enrichment. Use extract and the exact evidence IDs to nominate a newly discovered, independently substantial Theorem or Corollary for selection (include its actual heading and how its conclusion differs from existing cores); never insert one directly in the manuscript. For a local review inspect the changed blocks and their dependencies. If an already selected result is a direct special case or restatement, request a merge or removal with both source locations. Use draft for a source-grounded correction within the existing selection. Identify each actionable issue with the current text, original evidence, operation and specific change. When the schema supports reading requests, ask a concrete question only if the supplied evidence cannot settle it. An uncertain glyph is a reason to inspect its original page.

[visual]
Inspect the supplied rendered page against the page-layout rules. Return passed and the concrete visible issues. For each issue that can be localized, copy its description into locations with the corresponding draft_field. If the page passes, return empty issues and locations. Pass a readable page with ordinary prose line wraps, including a term separated from its inline variable or a single word on the last line. Report an actionable issue only when visible content is clipped, obscured, misassigned, detached from its mathematical conditions, or fails an actual page requirement.
